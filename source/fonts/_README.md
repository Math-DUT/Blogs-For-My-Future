Font sources used by this blog:

- Body: LXGW WenKai, as used by Phycat. The regular face is loaded from the pinned `lxgw-wenkai-webfont@1.7.0` stylesheet, which downloads Unicode subsets as needed.
  - https://github.com/lxgw/LxgwWenKai
  - https://github.com/chawyehsu/lxgw-wenkai-webfont
  - https://github.com/sumruler/typora-theme-phycat
- Code: `Monaco.ttf`, from https://github.com/todylu/monaco.ttf/blob/master/monaco.ttf. `custom.css` prefers an installed Monaco font and uses this bundled file otherwise.
